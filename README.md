# java-racingcar-precourse
## ✨기능 목록

### 자동차 이름 입력 기능
- [X] "경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)" 문구를 출력하여 사용자에게 입력을 유도한다.
- [X] 사용자의 입력을 쉼표(`,`) 기준으로 분리하여 자동차 이름 목록을 생성한다.
- [X] 각 자동차 이름의 길이가 1자 이상 5자 이하인지 검증한다.
- [X] 이름이 비어 있거나 5자를 초과할 경우 예외를 발생시킨다.

### 시도 횟수 입력 기능
- [X] "시도할 횟수는 몇 회인가요?" 문구를 출력하여 사용자에게 입력을 유도한다.
- [X] 사용자가 입력한 값을 정수로 변환하여 시도 횟수로 사용한다.
- [X] 시도 횟수가 1 이상인지 검증한다.
- [X] 음수, 0, 비정상 입력(문자 등)이 포함된 경우 예외를 발생시킨다.

### 자동차 전진 기능
- [X] 0에서 9 사이의 무작위 값을 구한다.
- [X] 무작위 값이 4 이상이면 자동차를 한 칸 전진시킨다.
- [X] 무작위 값이 4 미만이면 자동차는 멈춘다.
- [X] 시도 횟수만큼 모든 자동차에 대해 반복한다.

### 차수별 실행 결과 출력 기능
- [X] 각 시도(회차)마다 모든 자동차의 이름과 현재 이동 상태를 출력한다.
- [X] 전진 상태는 "-"로 표현하며, 누적된 "-"의 개수가 이동 거리를 의미한다.  
  (예: `pobi : ---`)
- [X] 각 회차의 출력 사이에는 한 줄 공백을 추가한다.

### 우승자 판별 및 결과 출력 기능
- [ ] 모든 시도가 끝난 후 가장 많이 전진한 자동차(들)를 우승자로 판별한다.
- [ ] 우승자가 한 명일 경우 `"최종 우승자 : pobi"` 형식으로 출력한다.
- [ ] 우승자가 여러 명일 경우 `"최종 우승자 : pobi, jun"` 형식으로 쉼표로 구분해 출력한다.
- [ ] 출력 형식이 요구사항과 정확히 일치해야 한다.

### 프로그램 실행 흐름
1. 자동차 이름 입력 → 검증
2. 시도 횟수 입력 → 검증
3. 시도 횟수만큼 자동차 이동 반복
4. 차수별 실행 결과 출력
5. 최종 우승자 출력


## ⚠️ 예외 처리 조건

### 예외 발생 시 처리 방식
- 사용자가 잘못된 값을 입력한 경우  
  → `IllegalArgumentException`을 발생시키고 프로그램을 종료한다.

### 형식 관련 예외
- [ ] 자동차 이름이 비어 있거나 쉼표로만 구분된 경우  
  (예: `"pobi,,jun"`, `"pobi,woni,"`)
- [ ] 자동차 이름이 5자를 초과하는 경우  
- [ ] 자동차 이름이 완전히 비어 있거나 공백으로만 구성된 경우

### 값 관련 예외
- [ ] 시도 횟수 입력이 숫자가 아닌 경우  
  (예: `"five"`, `"3a"`)
- [ ] 시도 횟수가 0 이하인 경우  
  (예: `0`, `-1`)

### 실행 관련 예외
- [ ] 위 조건 중 하나라도 위반 시 `IllegalArgumentException`을 발생시키고 프로그램을 종료한다.
- [ ] 예외 메시지를 출력 후 추가 입력을 받지 않고 종료해야 한다.
